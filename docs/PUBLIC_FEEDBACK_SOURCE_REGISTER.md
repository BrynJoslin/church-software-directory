# Public feedback source register

Checked: 26 July 2026

This register governs systematic public-feedback research. It records the default use position, not a licence to collect content automatically.

| Source type | Access route | Default use | Restriction |
| --- | --- | --- | --- |
| Supplier-selected testimonials | Supplier website | Exclude from independent synthesis | May support only a supplier-published claim when separately sourced. |
| Search engines | Manual search | Discovery only | Open and assess the underlying public source before relying on it. |
| Public app stores | Manual public page | Discovery or original anonymised notes only after terms review | No automated collection, copied bodies or personal data. |
| Public review platforms | Confirmed profile link | Link only unless specific permission allows more | No scraping, widgets, rating aggregation or AI processing where prohibited. |
| Public forums, Reddit and videos | Manual public page | Original anonymised notes if terms allow | Exclude closed, sign-in-only or high-risk material. |
| Licensed API or syndication | Documented permission | Use only within the applicable licence | Honour rate limits, minimisation and deletion duties. |

Before using a new source, record its terms URL, checked date, permission assessment, access route and any attribution, retention or deletion duties in the private evidence ledger. This public repository never stores raw review bodies, account names or other unnecessary personal data.

## Platform decisions checked 26 July 2026

| Platform | Decision | Reason |
| --- | --- | --- |
| Gartner properties, including Capterra, GetApp and Software Advice | Exclude review bodies from agent-assisted research and synthesis | Gartner's terms prohibit automated acquisition and use of its content as input to generative AI or derivative works. Retain a confirmed profile link only. |
| Google Play | Exclude review bodies from public synthesis | Google Play grants an end user a personal, non-commercial content licence; a directory summary is not within that default permission. Retain a confirmed profile link only. |
| Apple App Store | Link only pending explicit reuse permission | The applicable service terms do not grant this directory a clear right to create a public derivative summary of reviewer content. |
| Trustpilot | Link only pending licence or written permission | Trustpilot's consumer terms explicitly cover access through automated technologies. Use a profile only as a matched external link unless a suitable data licence permits the intended use. |
| Reddit and other public discussion forums | Case-by-case, manual-only | Do not use account names or copied content. Record the terms position and an original, anonymised note before relying on a discussion. |
